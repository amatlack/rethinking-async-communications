

# Repensando las comunicaciones asíncronas: Principios y prácticas para equipos remotos

En 2020, muchas empresas se vieron empujadas al trabajo remoto casi de la noche a la mañana, reaccionando a la pandemia sin tiempo para planificar o adaptarse. En lugar de repensar intencionalmente su forma de trabajar, la mayoría de las organizaciones simplemente trasladó rituales presenciales — como reuniones síncronas y actualizaciones constantes — a un entorno virtual. Como resultado, muchos equipos terminaron sobreviviendo, pero no prosperando.

Pero el trabajo remoto es más que un simple cambio de ubicación; es un cambio de mentalidad. Realizado correctamente, el trabajo remoto no solo replica los flujos de trabajo antiguos en línea — sino que los transforma. Dominar el arte del trabajo asíncrono permite que los equipos distribuidos colaboren de manera fluida entre distintas zonas horarias, minimizando las interrupciones y maximizando la productividad.

Este proyecto es una adaptación de [How GitHub Engineering Communicates](https://github.com/github/how-engineering-communicates), desarrollado originalmente por GitHub y publicado bajo una licencia [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/). Si bien está inspirado en la experiencia de GitHub, esta guía se ha generalizado para apoyar a una mayor variedad de equipos remotos.

A medida que el trabajo remoto continúa evolucionando, esta guía también lo hará. Las contribuciones y mejoras no solo son bienvenidas, ¡[se fomentan](.github/CONTRIBUTING.md)!
